# 🛒 Amazon Home Page Clone

A responsive front-end clone of the Amazon home page built using **HTML5** and **CSS3**. This project recreates the look and feel of Amazon's landing page, focusing on layout, styling, and responsive design without using JavaScript.

## 📌 Features

* Responsive navigation bar
* Amazon-inspired hero banner
* Product category cards
* Multi-column footer
* Clean and semantic HTML structure
* Modern CSS using Flexbox and Grid
* Responsive design for desktop and mobile screens

## 🛠️ Technologies Used

* HTML5
* CSS3

## 📂 Project Structure

```text
amazon-homepage-clone/
│── index.html
│── style.css
│── images/
│── README.md
```

## 🚀 Getting Started

1. Clone the repository:

```bash
git clone https://github.com/your-username/amazon_clone.git
```

2. Navigate to the project folder:

```bash
cd amazon_clone
```

3. Open `index.html` in your browser.

No installation or dependencies are required.
